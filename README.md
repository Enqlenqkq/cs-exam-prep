# 📚 CS 중간고사 완벽 대비 웹 애플리케이션 (Exam Prep Web App)

알고리즘 분석, 정보처리기술, 운영체제론, 데이터베이스 과목의 중간고사를 대비하기 위한 반응형 웹 애플리케이션입니다.

## 🌟 주요 기능
- **📖 4대 과목 심층 개념 정리**: 세부 수식, 도표, 비교표 및 단계별 프로세스 완벽 정리
- **🎲 과목별 100문항 실전 퀴즈 뱅크 (총 400문항 수록)**:
  - 과목당 100문항의 엄선된 예제를 독립 데이터 파일(`data/quiz_*.json` 및 `data/quiz_bank.js`)로 분리 저장
  - **랜덤 문제 추출**: 10문항 / 20문항 / 50문항 / 100문항 전체 선택 후 무작위 추출하여 실전 모의고사 진행
  - 자동 채점 및 문항별 정답/오답 시각화, 상세 해설 제공
- **📜 풀이 히스토리 & 실전 오답노트 대시보드**:
  - 지금까지 풀었던 모든 문제 풀이 기록을 `localStorage`에 자동 영구 보존
  - 종합 정답률 및 과목별 성취도(정답률 프로그레스 바) 실시간 시각화
  - 과목별 필터(알고리즘/정보처리/운영체제/데이터베이스) 및 상태 필터(전체/오답만/정답만) 지원
  - **오답 재시험 모드**: 틀린 문제들만 모아 즉시 재시험을 치르는 집중 복습 기능
  - 오답노트 인쇄 / PDF 저장 및 개별/전체 기록 삭제 지원
- **✍️ 실시간 로컬 필기장**: 브라우저 `localStorage` 기반 과목별 실시간 자동 저장 메모
- **📋 필기 모아보기 & 인쇄**: 작성한 모든 필기를 한 번에 모아서 확인, 클립보드 복사 및 인쇄 지원

## 🎯 수록 과목 및 100제 퀴즈 뱅크 범위
1. **📘 알고리즘 분석 (Analysis of Algorithms - 100제)**
   - `Lec 2`: 선형회귀 및 MSE 비용함수, 퍼셉트론 원리, 학습 규칙 및 XOR 한계, 초평면, 다층 퍼셉트론
   - `Lec 3`: 활성화 함수 5종 비교, 시그모이드 기울기 소실 및 0.25 한계, 경사하강법/로컬 미니마/안장점
   - `Lec 4`: 역전파(Backpropagation) 체인룰 유도, 계산그래프, CNN 합성곱/풀링, 스트라이드/패딩 공식
   - `Lec 5`: 정보이론 섀넌 엔트로피 및 크로스 엔트로피, 소프트맥스, RNN 구조, BPTT 및 장기의존성 문제
   - `Lec 6`: LSTM 3대 게이트 수식 및 셀 상태, 경사하강법 3대 변형(BGD vs SGD vs Mini-batch), 옵티마이저(Momentum, AdaGrad, RMSProp, Adam)
2. **💾 정보처리기술 (100제)**
   - `1장`: 컴퓨터 역사, 세대별 소자, 폰노이만 구조, 폰노이만 병목, CPS, 디지털 트윈 5대 성숙도 레벨, 양자컴퓨터
   - `5장`: 정보통신 구성, 전송 매체, 네트워크 토폴로지(스타/버스/링/메시), OSI 7계층 및 TCP/IP 4계층, CSMA/CD, CSMA/CA
   - `6장`: IPv4 vs IPv6, 서브넷팅, DNS 계층, HTTP 발전사(1.1 Keep-alive, 2.0 멀티플렉싱, 3.0 QUIC), 클라우드 SPI, MSA(Eureka, Ribbon, API Gateway), REST
   - `7장`: 멀티미디어 4대 특성, 나이퀴스트 표본화 정리, 표본화/양자화/부호화, 무손실/손실 압축(허프만, DCT, JPEG, H.264/H.265), VR/AR/MR, 메타버스 4대 영역
   - `8장`: 모바일 컴퓨팅, 5G 3대 시나리오(eMBB, URLLC, mMTC), 6G 전망, IoT 3계층, 엣지 컴퓨팅, OAuth 2.0 인가 흐름 4종, X.509 인증서, 제로 트러스트 3대 원칙
3. **⚙️ 운영체제론 (Operating Systems - 100제)**
   - `W1~W2`: 운영체제 2대 목적, 부트스트랩 로더, 이중 모드(User/Kernel) 및 모드 비트, 특권 명령, 트랩/인터럽트 벡터/ISR, 타이머, 시스템 콜 매개변수 전달 3방식, DMA 컨트롤러 및 사이클 스틸링
   - `W3`: 메모리 계층 구조, 참조 지역성(시간/공간), MMU 주소 변환, 연속 메모리 할당(First/Best/Worst-fit), 외부/내부 단편화, 페이징(Page/Frame, PTBR, TLB, EAT 계산, 다단계 페이징), 세그멘테이션
   - `W4`: ELF 바이너리 구조(ELF Header, Program/Section Header Table, .text, .data, .bss, .rodata), 프로세스 4대 메모리 레이아웃(Text, Data, Heap, Stack), PCB 필드, 5상태 전이 모델, 문맥 교환 오버헤드, fork/exec/wait/exit, 좀비/고아 프로세스
4. **🗄️ 데이터베이스 (Database Systems - 100제)**
   - `Chap 1`: 파일 시스템 한계(종속성·중복성), 데이터베이스 4대 정의 및 특성, ANSI/SPARC 3단계 스키마(외부/개념/내부) 및 2단계 데이터 독립성, DDL/DML/DCL, DBMS 아키텍처
   - `Chap 2`: 개념적 ER 모델링, 피터 첸 표기법, 복합/다중값/유도/키 속성, 약한 엔티티와 식별 관계, 관계의 차수 및 카디널리티(1:1, 1:N, N:M), 참여 제약조건(전체/부분 참여), 까마귀발(IE) 표기법
   - `Chap 3`: 관계 데이터 모델(E.F. Codd), 릴레이션 4대 특성, 차수와 카디널리티, Key의 5대 유형(슈퍼키, 후보키, 기본키, 대체키, 외래키), 무결성 제약조건 3대 원칙(개체, 참조, 도메인) 및 위반 시 조치(CASCADE, RESTRICT, SET NULL)
   - `Chap 3-1 보충`: ER-to-Relational Mapping (사상 기법) 7대 규칙 전수 정리

## 📂 모듈화된 프로젝트 구조
```text
├── index.html                   # 시맨틱 마크업 본체 (스타일/스크립트 외부 분리)
├── css/
│   └── style.css                # 반응형 디자인, 카드 레이아웃, 대시보드 스타일 전체
├── js/
│   ├── navigation.js            # 과목/탭/단원 전환 네비게이션 제어 모듈
│   ├── notes.js                 # 실시간 필기장, localStorage 자동 저장 및 모아보기
│   ├── quiz.js                  # 퀴즈 뱅크 랜덤 추출, 셔플, 렌더링, 채점 및 빈칸 퀴즈
│   ├── history.js               # 풀이 히스토리, 통계 대시보드, 필터링 및 오답 재시험
│   └── app.js                   # 메인 애플리케이션 진입점 및 KaTeX 자동 렌더링 초기화
└── data/
    ├── quiz_algorithms.json     # 알고리즘 분석 100문항 데이터셋
    ├── quiz_it.json             # 정보처리기술 100문항 데이터셋
    ├── quiz_os.json             # 운영체제론 100문항 데이터셋
    ├── quiz_db.json             # 데이터베이스 100문항 데이터셋
    └── quiz_bank.js             # 통합 퀴즈 뱅크 스크립트 (오프라인/로컬 CORS 없는 구동 보장)
```
