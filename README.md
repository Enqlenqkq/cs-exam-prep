# 📚 CS 중간고사 완벽 대비 웹 애플리케이션 (Exam Prep Web App)

알고리즘 분석, 정보처리기술, 운영체제론, 데이터베이스 과목의 중간고사를 대비하기 위한 반응형 웹 애플리케이션입니다.

## 🌟 주요 기능
- **📖 4대 과목 심층 개념 정리**: 세부 수식, 도표, 비교표 및 단계별 프로세스 완벽 정리
- **📝 실전 모의 퀴즈**: 객관식(감점 룰 토글) 및 주관식 단답형/빈칸 채우기 퀴즈와 자동 채점/상세 해설
- **✍️ 실시간 로컬 필기장**: 브라우저 `localStorage` 기반 과목별 실시간 자동 저장 메모
- **📋 필기 모아보기 & 인쇄**: 작성한 모든 필기를 한 번에 모아서 확인, 클립보드 복사 및 인쇄 지원

## 🎯 수록 과목
1. **📘 알고리즘 분석 (Analysis of Algorithms)**
   - 선형회귀 및 MSE 비용함수
   - 퍼셉트론 원리, 학습 규칙 및 XOR 한계
   - 활성화 함수 5종 비교 및 경사하강법/로컬 미니마
   - 역전파(Backpropagation) 체인룰 유도 및 CNN 합성곱/풀링
   - 순환신경망(RNN), BPTT, 정보이론 기반 크로스 엔트로피 유도
   - LSTM 3대 게이트 수식 및 경사하강법 3대 유형(BGD vs SGD vs Mini-batch)
2. **💾 정보처리기술**
   - 컴퓨터 발전과 정보사회 (엘빈 토플러, 마샬 맥루한, IT 3대 법칙)
   - 정보통신 전송 방식, 네트워크 토폴로지, OSI 7계층 및 보안 3요소(CIA)
   - 인터넷 역사(ARPANET), TCP/IP, IPv4 vs IPv6, DNS, 웹 2.0 및 클라우드 모델
   - 멀티미디어 4대 특성, 비트맵 vs 벡터, 무손실/손실 압축 및 MPEG 발전사
   - 모바일 앱 3대 개발 방식(네이티브/웹/하이브리드), LBS, 증강현실(AR), 스마트워크
3. **⚙️ 운영체제론 (Operating Systems)**
   - 컴퓨터 하드웨어 구조, 인터럽트 메커니즘, 이중 모드(사용자/커널) 및 시스템 호출
   - C 라이브러리 `fread()` vs 시스템 호출 `read()` 버퍼링 성능 분석
   - 메모리 계층 구조, 참조 지역성(시간/공간), MMU 주소 변환 및 메모리 보호
   - 연속 메모리 동적 할당 3대 알고리즘(First-fit, Best-fit, Worst-fit), 단편화 및 페이징/세그멘테이션
   - ELF 파일 메모리 4대 영역(Text, Data, BSS, Heap, Stack), 프로세스 5대 상태 전이
   - 프로세스 생성(fork, exec, wait), 좀비/고아 프로세스, 요구 페이징 6단계 Page Fault 시퀀스, 스래싱
4. **🗄️ 데이터베이스 (Database Systems)**
   - 파일 시스템 한계, 3단계 스키마(외부/개념/내부) 및 2단계 데이터 독립성
   - ER 모델링(엔티티, 관계, 다중값/복합/유도 속성), 참여 제약조건, 약한 엔티티 타입
   - 관계 데이터 모델 용어(튜플, 카디널리티, 차수), Key의 5가지 종류(슈퍼키, 후보키, 기본키, 대체키, 외래키)
   - 무결성 제약조건 3대 원칙(개체, 참조, 도메인) 및 참조 무결성 위배 시 처리 옵션(CASCADE 등)
   - ER-to-Relational Mapping (사상 기법) 8대 케이스 전수 정리
